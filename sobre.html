Sobre o UrbanFlow

Projeto conceitual focado em mobilidade urbana, experiência do usuário e consulta de rotas.

Objetivo


UrbanFlow foi criado para demonstrar uma experiência moderna de consulta de ônibus, rotas e informações de transporte público através de uma interface simples, responsiva e acessível.


Tecnologias


  • HTML5
  • CSS3
  • JavaScript
  • OpenStreetMap
  • Leaflet
  • GitHub Pages
