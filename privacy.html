Política de Privacidade

Como o UrbanFlow utiliza e protege as informações neste ambiente demonstrativo.

Armazenamento local

O UrbanFlow utiliza o armazenamento local (localStorage) do navegador para guardar apenas dados necessários à demonstração:

  • Nome informado na tela de entrada
  • Preferência de tema claro ou escuro
  • Registro do aceite dos Termos de Uso
  • Data do último aceite registrado

Informações coletadas diretamente

O login é simulado. Nenhuma senha é solicitada e não existe autenticação real. Os dados não são enviados por este projeto para um servidor próprio.

Serviços externos

Recursos como OpenStreetMap, Leaflet e bibliotecas carregadas por serviços externos podem receber dados técnicos da conexão, como endereço IP e informações de acesso, conforme suas próprias políticas.

Exclusão dos dados

Você pode apagar os dados locais a qualquer momento nas configurações do navegador, removendo os dados armazenados para este site.

Atualizações desta política

Esta política pode ser revisada quando novas funcionalidades forem incorporadas ao projeto.
